Mikaelson Institute for African Studies

-------------------------------------------------------------
WHAT TO USE WHERE
-------------------------------------------------------------

svg/            Vector. Use these wherever you can — they scale
                to any size with no quality loss and can be
                recoloured. No embedded fonts, so they open
                identically everywhere.

  mark-primary-light .............. Default. Teal bands, Lagoon
                                    horizon, transparent ground.
                                    Use on parchment or white.
  mark-primary-dark ............... Parchment bands, Turquoise
                                    horizon, transparent ground.
                                    Use on Institute Teal or black.
  mark-primary-light-on-parchment . Same, with the parchment
                                    ground baked in.
  mark-primary-dark-on-teal ....... Same, with the teal ground
                                    baked in. Good for social
                                    avatars, which reject
                                    transparency.
  mark-tonal ...................... Five ages of the same ink.
                                    Reserved for the Framework
                                    timeline and publication
                                    covers.
  mark-single-ink ................. One colour, #14262A. Print,
                                    stamps, embossing, fax,
                                    greyscale.
  mark-single-parchment ........... One colour, #E9E1D8. The same
                                    reduction for dark grounds.
  favicon-cut-light / -dark ....... FOUR-band reduction. Use ONLY
                                    below 24px — favicon, app
                                    icon, tiny UI. Never larger.

png/            Raster, 2048px and 512px, transparent where the
                SVG is transparent. Use when SVG is not accepted
                (Canva free plan, some social uploaders, Word).
                2048px is far beyond HD for print or slides.

lockups/        Mark plus type, 4x resolution PNG.
  lockup-horizontal-light / -dark . Primary. Site header,
                                    letterhead, email signature.
  lockup-stacked-light / -dark .... Covers, certificates, square
                                    formats.
  lockup-endorsement .............. Parent relationship. Footers,
                                    partner decks, About page.

-------------------------------------------------------------
COLOURS
-------------------------------------------------------------

  Institute Teal    #003E45   Primary. Inherited from the
                              Mikaelson Initiative unchanged.
  Lagoon            #0E7C88   MIAS accent — the horizon band.
                              The one colour MIAS owns.
  Turquoise         #5CE1E6   Parent primary. DARK GROUNDS ONLY
                              (1.2:1 on parchment — it fails).
  Parchment         #E9E1D8   Page ground, and the bands when
                              reversed.
  Ink               #14262A   Body text and the single-ink cut.

-------------------------------------------------------------
RULES
-------------------------------------------------------------

  1. Clear space on all four sides equals the height of the
     tallest band. Nothing enters it.
  2. Minimum 24px for the standard mark. Below that, the
     favicon cut.
  3. Never stretch, rotate, outline, add a gradient, round the
     band ends, or make the bands equal — the unequal measure
     is the idea.
  4. The horizon band is Lagoon on light and Turquoise on dark.
     No other colour.
  5. The mark must stay recognisable with the horizon removed —
     never let colour alone carry it.

-------------------------------------------------------------
UPLOADING TO CANVA
-------------------------------------------------------------

  Uploads -> Upload files -> select the svg/ folder.
  SVG upload requires Canva Pro. On a free plan upload png/
  instead.

  Canva can recolour an uploaded SVG; it cannot recolour a PNG.
  If you need a colourway that is not in the pack, ask rather
  than recolouring a PNG by hand.

-------------------------------------------------------------
KNOWN LIMITATION
-------------------------------------------------------------

  Lockups are PNG only. Their type is live text, so an SVG
  would require Spectral and IBM Plex Mono to be installed
  wherever it opens, and Canva would silently substitute a
  different typeface. Editable vector lockups require the type
  to be converted to outlines in a vector editor — a
  production step, not done here.

  Typography (Spectral / Archivo / IBM Plex Mono) departs from
  the Mikaelson Initiative guide, which specifies Grift and
  Inter. This is pending Michael's approval; the mark and the
  palette are unaffected either way.
